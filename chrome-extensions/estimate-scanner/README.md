# 見積もり逆算スキャナー（Chrome拡張機能）

クライアントが「こんな感じのサイトで」と出してきた参考サイトから、**見積もりのたたき台**を作るツールです。

- **ページ数**：`robots.txt` と `sitemap.xml` から数えます（無いサイトは、リンクをたどって推定）
- **「一覧＋詳細」になりそうなページ**（お知らせ・ブログ・実績など）と、**固定ページ** を分け、**テンプレートの種類**を推定
- 下層ページもいくつか開いて、**フォーム**（お問い合わせページなど）・**多言語**・**検索**・**会員**・**カート**・**地図**・**動画**・**スライダーやスクロール連動の動き** を確認
- **WordPress・Shopify・STUDIO・Next.js・jQuery** などの技術を検出
- 「数量 × 単価」で内訳を作り、**ディレクション費と見積もりの幅（±20%）** を付けて合計を出します
- **Excel・スプレッドシートにそのまま貼れる形**（TSV）と、Markdown でコピー

## インストール

1. このリポジトリを GitHub の「Code → Download ZIP」でダウンロードして展開します
2. Chrome で `chrome://extensions` を開き、右上の **デベロッパーモード** をオンにします
3. **パッケージ化されていない拡張機能を読み込む** で `chrome-extensions/estimate-scanner/extension` を選びます

動作環境：Chrome 116 以降

## 使い方

1. 参考サイトのトップページを開き、ツールバーのアイコンでサイドパネルを開きます
2. **このサイトを解析する**（下層ページも最大12ページ確認します。数十秒かかることがあります）
3. **見積もり** タブで内訳を確認
   - 不要な項目はチェックを外す、数量は手で直す（例：テンプレートを統合できそうなら減らす）
   - 調整した内容はサイトごとに保存されます
4. **Excel用にコピー** で見積書のひな形に貼り付けます

### 見積もりの項目と初期の単価

初期の単価は**仮の金額**です。「単価の設定」タブで自社の金額に置き換えてください（すべての見積もりに反映されます）。

| 項目 | 数量の出し方 | 仮の単価 |
| --- | --- | ---: |
| 情報設計・ワイヤーフレーム | テンプレートの数 | 30,000円 |
| デザイン（トップ / 下層テンプレート） | 1式 / 下層テンプレートの数 | 150,000円 / 60,000円 |
| コーディング（トップ / 下層テンプレート / 量産ページ） | 1式 / 下層テンプレートの数 / テンプレート以外の固定ページ | 100,000円 / 40,000円 / 10,000円 |
| CMS構築（基本設定 / 一覧・詳細） | 一覧があるか現行がCMSなら1式 / 一覧の種類 | 150,000円 / 80,000円 |
| フォーム | 見つかったフォーム（同じ形は1つ） | 50,000円 |
| アニメーション・動き | スライダー・スクロール連動・パララックス・Lottie・3Dの種類 | 30,000円 |
| 地図・動画の埋め込み | 種類 | 10,000円 |
| サイト内検索 | 検索ボックスがあれば1式 | 50,000円 |
| 多言語対応 | 追加の言語数 × デザイン＋コーディングの30% | — |
| ディレクション | 小計の15% | — |
| 会員機能・EC・チャット連携 | 見つかったら「要個別見積もり」として表示（金額には含めない） | — |

### テンプレートの推定方法

- 第1階層の下に詳細ページが10件以上（または数字・日付のURLが多い）→「一覧＋詳細」（2種）
- 固定ページは第1階層ごとに1種、子ページが4つ以上あれば親と子で2種（固定ページは最大12種）
- テンプレートに含まれない固定ページは「量産ページ」として数えます
- `/news/page/2/` のようなページ送りや、PDF・画像は数えません

## 注意

- 公開されている情報から機械的に推定した**たたき台**です。原稿作成・撮影・保守運用・サーバー費用は含みません
- ログインが必要なページや、JavaScriptで後から表示されるページは数えられないことがあります
- 解析のために、参考サイトの `robots.txt`・`sitemap.xml`・最大12ページにアクセスします

## 開発者向け
