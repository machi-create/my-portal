# 合意ピン（Chrome拡張機能）

ページの要素に **「決まったこと・確認者・日付」をピン留め** して、「言った・言わない」を防ぐツールです。

- 決まったことを、関係する要素（見出し・ボタン・画像など）にひも付けて記録します
- あとでページを開くと、要素の右上に番号が出ます。**ホバーで経緯**（保留 → 合意 など）を表示
- **テスト環境で記録したピンを、本番でも表示**できます（同じパスのページ）
- ページが改修されてクラス名などが変わっても、**文言から要素を見つけ直します**
- 議事録用の **Markdown**、Excel用の **CSV**、チーム共有用の **JSON** で書き出せます

## インストール

1. このリポジトリを GitHub の「Code → Download ZIP」でダウンロードして展開します
2. Chrome で `chrome://extensions` を開き、右上の **デベロッパーモード** をオンにします
3. **パッケージ化されていない拡張機能を読み込む** で `chrome-extensions/agreement-pins/extension` を選びます

動作環境：Chrome 116 以降

## 使い方

1. ページを開き、ツールバーのアイコンでサイドパネルを開きます
2. **＋ ピンを追加** → 関係する要素をクリック（`↑` `↓` キーで選択範囲を調整できます）
3. 状態（合意 / 保留 / 要確認 / 却下）、決まったこと、確認者、日付を入れて **保存**
4. 状況が変わったら、ピンの **経緯を追加**（例：10/1 保留 → 10/14 合意）

| 操作 | 内容 |
| --- | --- |
| ピンをクリック（一覧） | ページの該当要素までスクロールして点滅 |
| ページ上の番号にホバー | 最新の内容と、これまでの経緯をカードで表示 |
| ページ上の番号をクリック | サイドパネルで該当ピンを開く |
| 位置を付け直す | 要素が見つからなくなったときに、選び直す |

アイコンの数字はそのページのピンの数です（保留・要確認があるとオレンジ、すべて合意なら緑）。

### すべての合意

全ページのピンを、ページごとにまとめて表示します。状態で絞り込んだり、内容・確認者で検索したりできます。

| 書き出し | 用途 |
| --- | --- |
| Markdownをコピー | 議事録・Backlog・Notion に貼り付け（ページごとの表＋経緯） |
| CSVを保存 | Excel・スプレッドシートで管理 |
| JSONで書き出し / 読み込む | チームでの共有・バックアップ。読み込むと、同じピンは履歴をまとめ、新しいピンは追加します |

## 設定

- **自動でピンを表示**：ピンのあるページを開いたら、サイドパネルを開かなくても番号を表示
- **別のドメインでも表示**：同じパスなら、テスト環境 ↔ 本番 のピンを共通で表示
- **あなたの名前**：ピンに「記録者」として残します

## 注意

- ピンはこのパソコンの Chrome に保存されます。ほかの人と共有するときは JSON を書き出して渡してください
- 要素の見つけ直しは「CSSセレクタ → 同じ種類の要素の中で文言が近いもの」の順に行います。文言も大きく変わった場合は「位置を付け直す」を使ってください
