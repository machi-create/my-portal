# テストアップチェッカー（Chrome拡張機能）

Webディレクター向けの「テストアップ確認」ツールです。サイドパネルで次の2つを行います。

| 機能 | できること |
| --- | --- |
| **原稿照合** | 原稿（貼り付け・Googleスプレッドシート/ドキュメントのURL・CSV）とページの文言を突き合わせ、違う箇所をページ上で色付けします |
| **公開前チェック** | noindex・ダミー文言・仮画像・テスト環境URLの混入・リンク切れなど、公開前の「消し忘れ」を一覧にします |

照合とチェックはすべてブラウザ内で処理します。原稿やページの内容を外部サービスへ送ることはありません。

---

## インストール

1. このリポジトリを GitHub の「Code → Download ZIP」でダウンロードして展開します
2. Chrome で `chrome://extensions` を開きます
3. 右上の **デベロッパーモード** をオンにします
4. **パッケージ化されていない拡張機能を読み込む** を押し、`chrome-extensions/testup-checker/extension` フォルダを選びます
5. ツールバーのパズルアイコンから「テストアップチェッカー」をピン留めしておくと便利です

> ローカルのHTMLファイル（`file://`）も確認したい場合は、拡張機能の「詳細」で **ファイルの URL へのアクセスを許可する** をオンにしてください。

動作環境：Chrome 116 以降

> 拡張機能を新しいバージョンに入れ替えたときは、`chrome://extensions` で更新ボタンを押したあと、確認中のページも再読み込みしてください。

---

## 使い方

確認したいページを開いた状態で、ツールバーのアイコンをクリックするとサイドパネルが開きます。

### 1. 原稿照合

1. 原稿を貼り付けます（または「URL」「ファイル」から読み込み）
2. **照合する** を押します（テキスト欄で `Ctrl / ⌘ + Enter` でも実行できます）
3. 結果をクリックすると、ページ上の該当箇所までスクロールして点滅します

| 判定 | 意味 | ページ上の色 |
| --- | --- | --- |
| 一致 | 原稿どおり | 薄い緑 |
| 表記ゆれ | 全角/半角・大文字/小文字・記号の違いだけ（例：`15` と `１５`、`Web` と `ＷＥＢ`） | オレンジ＋波線 |
| 文言差分 | 似ているが文言が違う。赤の取り消し線＝原稿にだけある、緑の下線＝ページにだけある | 黄色＋赤い波線 |
| 未反映 | ページに見当たらない（近い箇所があれば「近い箇所」として表示） | － |
| 原稿にない | ページにだけある文言（ヘッダー・ナビ・フッターは除外） | 紫＋点線 |

**原稿の書き方のコツ**

- 1行（表なら1セル）が1つの要素として扱われます。Excel・スプレッドシートのセル範囲はそのままコピペできます
- `【見出し】` `【H1】` `【リード】` などのラベル、行頭の `■` `・` `##` は自動で外します
- `//` `※指示` `※修正` で始まる行は、制作への指示として無視します（照合オプションで変更可）
- `title`・`meta description`・画像の `alt`・ボタンの文言も照合の対象です
- 閉じたアコーディオンの中など、非表示の要素も照合します（結果に「非表示の要素」と表示）
- 原稿はページのURLごとに自動で保存されます。テスト環境と本番でパスが同じなら、本番でも同じ原稿が呼び出されます

**照合オプション**

| 項目 | 内容 |
| --- | --- |
| 照合する列 | 表のときに照合する列（`C`、`C,D`、`B-D`、`3` など）。「箇所」「備考」列を除きたいときに |
| 1行目は見出し行として除外 | 表の1行目を読み飛ばします |
| 照合する範囲 | CSSセレクタ（例：`main`、`#content`）でページの一部だけを対象にします |
| ページを再読み込みしたら自動で再実行 | 修正 → 再読み込みのたびに照合し直します |

**原稿の読み込み元**

- **Googleスプレッドシート / ドキュメント**：URLをそのまま貼り付けます。共有設定が「リンクを知っている全員」か、Chromeでログイン中のアカウントで閲覧できるファイルに対応します（スプレッドシートは表示中のシートを読み込みます）
- **CSV / TSV / TXT / Markdown**：ファイルを選ぶかドロップします。日本語版Excelで保存した Shift_JIS のCSVも読めます
- Excel（.xlsx）は直接読めないため、CSVで保存するかセルをコピーして貼り付けてください

### 2. 公開前チェック

**チェックする** を押すと、問題のある箇所をカテゴリ別に一覧にし、ページ上でも枠線と色で示します。結果はクリックで該当箇所に移動できます。

| カテゴリ | 主なチェック内容 |
| --- | --- |
| ダミー・仮素材 | 「テキストテキスト」「ダミーテキスト」「（仮）」「○○」「×××」「XXX」「hoge」「Lorem ipsum」、WordPressの初期投稿、「TODO」「要差し替え」、03-0000-0000 などのダミー番号、test@ や example.com のメールアドレス、「準備中」「近日公開」 |
| リンク・URL | テスト環境・ローカル（stg. / dev. / localhost / 社内IP など）へのリンクや読み込み、example.com、`href="#"` や href のないリンク、電話番号リンクの全角・番号違い、メールのダミー・表示違い、http:// の混在 |
| SEO・メタ情報 | noindex（本番は要修正／テスト環境は無いと注意）、title、meta description、OGP（相対パスの og:image）、canonical・og:url がテスト環境を指していないか、lang、viewport、ファビコン、h1 |
| 画像 | placehold.jp・dummyimage.com などの仮画像、dummy・sample・nowprinting などのファイル名、表示されない画像、alt のない画像、表示サイズに対して大きすぎる画像 |
| 計測タグ | GA4・GTM・旧UA・Google広告・Metaピクセル・Clarity の検出（本番で未設置なら注意） |
| 表記・誤字 | 「。。」「をを」などの重複、半角カタカナ、全角英数字、句読点の混在 |
| 表示・法務 | ©の年が古い、No.1・最上級表記に根拠の注釈があるか、フォームがあるのにプライバシーポリシーへのリンクがない |

**リンク切れをチェック** を押すと、ページ内のリンク先（最大150件）に実際にアクセスして、404・サーバーエラー・接続できないリンクを探します。

**結果をコピー** で、Slack や Backlog にそのまま貼れるテキストのレポートになります。

### 3. 設定（本番・テスト環境の登録）

- **本番ドメイン / テスト環境ドメイン**：1行に1つ。`*.example.com` でサブドメインもまとめて指定できます。公開前チェックの画面から「このドメインを本番 / テスト環境として登録」でも登録できます
- 未登録でも `stg.` `dev.` `test.` `localhost` などはテスト環境と自動で判定します
- **自動チェック**：登録したドメインのページを開くと公開前チェックを自動で行い、アイコンにエラー件数を表示します。本番ドメインでエラーがあると、ページの右下に通知も出ます（ローンチ当日の最終確認に）

## 権限について

| 権限 | 用途 |
| --- | --- |
| すべてのサイトへのアクセス | 開いているページの文言を読み取り、ハイライトを表示するため。原稿URLの読み込みとリンク切れチェックのため |
| scripting | ページに照合・チェック用の処理を差し込むため |
| storage | 設定と、ページごとの原稿を保存するため（設定はChromeの同期、原稿はこのパソコン内に保存） |
| sidePanel | サイドパネルを表示するため |

外部への通信は「原稿URLの読み込み」「リンク切れチェック」と、確認中のサイト自身への確認（`X-Robots-Tag` ヘッダー・`/favicon.ico`）だけです。

## 制限事項

- iframe の中の文言は対象外です
- Web Components は open な Shadow DOM のみ対象です
- 「原稿にない文言」は4文字以上の文字（数字・記号を除く）が続く部分だけを表示します
- 色付けには CSS Custom Highlight API（Chrome 105以降）を使っています

## 開発者向け

```
extension/
  manifest.json
  background.js          自動チェック・バッジ・後片付け
  lib/                   正規化・差分・原稿の分割・設定（パネルとページの両方で使用）
  content/               ページ側の処理（照合・チェック・ハイライト）
  sidepanel/             サイドパネルのUI
test/
  unit.test.mjs          ライブラリの単体テスト
  e2e.mjs                Chromiumに拡張機能を読み込んだ動作テスト
  fixtures/              テスト用のページと原稿
```

```sh
# 単体テスト
node --test test/unit.test.mjs

# 動作テスト（Playwright が必要。スクリーンショットを残す場合は TUC_SHOTS を指定）
node test/e2e.mjs
TUC_SHOTS=./shots node test/e2e.mjs
```
