# 工数オートログ（Chrome拡張機能）

見ているWebページから、**案件ごとの作業時間を自動で記録**するツールです。Backlog・Figma・Googleドキュメント・テスト環境など、ブラウザでの作業時間をプロジェクトに振り分け、**日報の文面とCSV**をワンクリックで作ります。

- 記録はタイマー不要。ページを見ているだけで記録します（サイドパネルを閉じていても記録します）
- 操作のない時間・Chromeを使っていない時間は数えません。オンライン会議など音が出ているタブがあれば、操作がなくても会議の時間として記録します（会議中に別のタブで資料を見ていても、会議のタブを記録）
- 「未分類」の一覧から、サイトやファイルを1クリックで振り分け。**過去の記録にもさかのぼって反映**されます
- 記録はこのパソコンのChromeの中だけに保存され、外部には送りません

## インストール

1. このリポジトリを GitHub の「Code → Download ZIP」でダウンロードして展開します
2. Chrome で `chrome://extensions` を開き、右上の **デベロッパーモード** をオンにします
3. **パッケージ化されていない拡張機能を読み込む** で `chrome-extensions/time-autolog/extension` を選びます

動作環境：Chrome 116 以降

## 使い方

ツールバーのアイコンでサイドパネルを開きます。アイコンには、いま見ている案件の今日の合計時間が出ます（未分類のページは「?」、一時停止中は「停止」）。

### 1日

- **記録中の状態**：いま記録しているプロジェクトとページ。未分類なら「振り分ける」からその場で振り分けられます
- **プロジェクト別**：その日の合計時間と割合。クリックすると、よく見たページの内訳が出ます
- **1日の流れ**：時間帯ごとの作業を帯で表示。「記録の一覧」から、まとまりごとに振り分け直し・削除ができます
- **＋ 手入力**：会議・電話・外出など、ブラウザの外の作業を追加します。手入力した時間は、同じ時間帯の自動記録より優先されます
- **未分類**：振り分けていないサイト・ページの一覧。「振り分ける」で、プロジェクトを選ぶ・新しく作る・記録しないサイトにする、が選べます
- ‹ › と日付から、ほかの日の記録を見られます

### 集計

今週・先週・今月・先月の、日ごとの工数（積み上げ棒グラフ）とプロジェクト別の合計です。棒にマウスを合わせると内訳が出ます。「表で見る」で日付×プロジェクトの表になります。

**CSVで書き出す**：「集計（日付×プロジェクト）」と「明細（記録ごと）」の2種類。Excelでそのまま開けます。

### 日報

その日の工数を、日報に貼れる文面にします。

```
【10月15日（木）の工数】合計 6.50h
■ A社サイトリニューアル　3.25h
　デザイン確認、要件定義書の修正
■ B社LP制作　2.00h
■ 社内MTG　1.25h
```

- 時間の表し方（1:30 / 1.50h）、丸め（5分・15分・30分単位）を選べます。丸めると0になる短い作業は、省略したことを注記します
- 「作業内容のメモ」に書いた内容が、プロジェクトの下に入ります（自動保存）
- 「よく見たページ」を入れると、作業内容を思い出す手がかりになります

### 設定

**プロジェクト**ごとに、振り分けのルールを1行に1つ書きます。

| 書き方 | 意味 |
| --- | --- |
| `a-sha.co.jp` | このドメインのページ（サブドメインも含む） |
| `test.example.net/a-sha/` | このURLで始まるページ |
| `figma.com/*/AbC123` | `*` は「何でもよい」 |
| `localhost:3000` | 開発中の環境（ポート番号つき） |
| `title:A社` | ページタイトルに「A社」を含む（Gmailのスレッド・Googleドキュメントなどに便利） |
| `# メモ` | `#` から後ろは無視されます |

複数のルールに当てはまるときは、**タイトル → URL → ドメイン**の順に、細かいルールが優先されます。たとえば「社内」に `docs.google.com`、「A社」に `title:A社` と書くと、タイトルに「A社」を含むドキュメントだけがA社になります。

未分類から振り分けるときは、サービスに合わせてルールを自動で作ります。

| サービス | 振り分けの単位 |
| --- | --- |
| Googleドキュメント・スプレッドシート・スライド・ドライブ | ファイル・フォルダごと |
| Figma | ファイルごと |
| Backlog | プロジェクト（課題キー）ごと |
| GitHub・GitLab | リポジトリごと |
| Slack（ブラウザ版） | チャンネルごと |
| Notion・Miro・Canva | ページ・ボードごと |
| そのほか | ドメインごと |

そのほかの設定：

- **記録しないサイト**：個人的な利用など。プロジェクトと同じ書き方です
- **操作がないとき**：1〜15分で休止（初期値は5分）
- **音が出ているタブは記録を続ける**／**ほかのアプリを使っているときも記録する**／**アイコンに時間を表示する**
- **記録の保存期間**：30日〜ずっと（初期値は180日）
- **設定を書き出す・読み込む**：プロジェクトとルールをチームで共有できます。読み込むと、今の設定に追加されます（同じ名前のプロジェクトにはルールを足します）

## 記録するもの・しないもの

| 記録する | 記録しない |
| --- | --- |
| 前面にあるタブのドメイン・URLのパス・ページタイトル・時間 | URLの `?` 以降と `#` 以降（検索語やIDが含まれることがあるため） |
| | 操作のない時間（音が出ているタブを除く）・画面ロック中 |
| | Chromeが前面にない時間（設定で変更できます） |
| | シークレットウィンドウ・Chromeの設定画面など、Webページ以外 |
| | 「記録しないサイト」・一時停止中 |

## 注意

- ブラウザの外の作業（デスクトップアプリ・会議室での打ち合わせなど）は記録できません。「＋ 手入力」で追加してください
- 操作がないかの判定は、パソコン全体のキーボード・マウスの操作をもとにします
- 記録は1分ごとに確定します。ブラウザが異常終了した場合、最大1分ぶんが失われることがあります。スリープ中の時間は数えません
- 記録はこのパソコンのChromeだけに保存されます。ほかのパソコンとは同期しません。拡張機能を削除すると記録も消えるため、必要ならCSVで書き出してください

## 開発者向け

```sh
node --test chrome-extensions/time-autolog/test/unit.test.mjs
node chrome-extensions/time-autolog/test/e2e.mjs
```

- `extension/lib/rules.js` … 振り分けルールの解釈・判定・提案
- `extension/lib/log.js` … 1日ごとの記録（区間）の操作
- `extension/lib/track.js` … 設定と「いま記録するか」の判定、設定の共有
- `extension/lib/report.js` … 集計・日報・CSV
- `extension/background.js` … 自動記録（記録の書き換えはすべてここで順番に行う）
