# LP抑揚グラフ（Chrome拡張機能）

LPの「抑揚」を、スクロール位置ごとのグラフで見える化するツールです。

- 画面の半分ごとに **文字量** と **画像の割合** を測り、**申し込みボタン**と**見出し**の位置と一緒に縦長のグラフにします（上がページの上端）
- **ボタンが長く出てこない区間**・**文字が続く区間**・**余白が続く区間** を見つけて、ページの左端にも帯で表示
- ファーストビュー（最初の1画面）に見出し・ボタン・画像があるか、画面に追従するボタンがあるかを確認
- 競合LPや改修前のLPを保存して、**同じ目盛りで並べて比較**（数字の比較表つき）

## インストール

1. このリポジトリを GitHub の「Code → Download ZIP」でダウンロードして展開します
2. Chrome で `chrome://extensions` を開き、右上の **デベロッパーモード** をオンにします
3. **パッケージ化されていない拡張機能を読み込む** で `chrome-extensions/lp-rhythm/extension` を選びます

動作環境：Chrome 116 以降

## 使い方

1. LPを開き、ツールバーのアイコンでサイドパネルを開くと、自動で計測します（ページを再読み込みすると測り直します）
2. **気づき** をクリックすると、ページのその区間へ移動します
3. グラフの行にマウスを乗せると、その位置の文字数・画像の割合・ボタン・見出しを表示。クリックでページのその位置へ移動します
4. **表で見る** で、グラフと同じ内容を表で確認できます
5. **比較用に保存** で名前を付けて保存 → **比較** タブで3つまで選んで並べます

### グラフの見方

| 表示 | 意味 |
| --- | --- |
| 青い棒（文字量） | その位置にある文字の数（同じグラフ内で比べられる目盛り） |
| 緑の棒（画像の割合） | 画面の幅に対して、画像・動画・背景画像が占める割合（0〜100%） |
| オレンジの点 | 申し込みボタン（ボタンらしい見た目のリンク・ボタン） |
| 左の黒い線 | 見出し（長い線ほど上位：H1 > H2 > H3） |
| 左の黄色い帯 | 気づきで「注意」になった区間 |

文字量と画像の割合は単位が違うため、1つのグラフに重ねず、同じ縦軸（ページの位置）を共有する2つのグラフに分けています。

### 気づきの基準

| 気づき | 基準 |
| --- | --- |
| 申し込みボタンがない区間 | ボタンとボタンの間（先頭・末尾を含む）が3画面以上（4画面以上のLP） |
| 文字が続く区間 | 画面の半分に350字以上・画像12%未満が2画面以上続く |
| 余白が続く区間 | 画面の半分に30字未満・画像15%未満が2画面以上続く |
| ボタンが少なめ | 6画面以上で、ボタンが2個未満 |
| 追従ボタン | 8画面以上のLPで、画面に固定されたボタンがない（情報） |
| ファーストビュー | 最初の1画面に、H1/H2の見出し・ボタンがあるか |

## 注意

- いま開いている画面サイズで計測します。スマホでの抑揚を見るときは、デベロッパーツールのデバイスモードで画面を切り替えてから「計測する」を押してください
- 画面に固定された要素（ヘッダー・追従ボタン）は、文字量・画像の割合には含めません
- 保存したLPはこのパソコンの Chrome に保存されます

## 開発者向け

```sh
node --test chrome-extensions/lp-rhythm/test/unit.test.mjs
node chrome-extensions/lp-rhythm/test/e2e.mjs
```

グラフの配色は、カテゴリ配色の検証スクリプトでライト・ダークの両方を確認した色（青・オレンジ・緑）を使っています。
