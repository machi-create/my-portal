# ペルソナ憑依モード（Chrome拡張機能）

ユーザーになりきってページを見るツールです。ペルソナを選ぶと、**その人の見え方を再現**し、**つまずきそうな箇所をページから自動で探して**、その人の口調の「ひとりごと」にします。

| ペルソナ | 見え方の再現 | 探すつまずき |
| --- | --- | --- |
| 65歳・老眼・スマホに不慣れ | ぼかし・レンズの黄ばみ・コントラスト低下（＋ズーム125%） | 16px未満の文字、色の差が7未満の文字、44px未満のボタン、カタカナ語・業界用語、60字を超える文、「こちら」リンク |
| 色の見え方が違う（P型・D型・T型） | 色覚の見え方（Machado ほか 2009 の行列） | 色だけで区別しているリンク、色の差が4.5未満の文字 |
| 片手で急いでいる会社員（スマホ） | 親指の届く範囲（右手・左手） | 44px未満のボタン、固定ヘッダー・バーの面積、画面を覆う表示、ボタンが親指の届く位置にあるか、1画面目のボタン、長い文 |
| 弱視（ぼやけて見える） | 強いぼかし・コントラスト低下（＋ズーム125%） | 18px未満の文字、色の差、名前のないボタン、「こちら」リンク |
| 電波の弱い場所でスマホを使う人 | — | 低速回線での表示時間の目安、重いファイル、表示を止める読み込み、自動再生の動画 |
| 初めて訪れた人（業界に詳しくない） | — | 業界用語・略語、長い文、「こちら」リンク、1画面目に何のページかわかる見出しがあるか |

## インストール

1. このリポジトリを GitHub の「Code → Download ZIP」でダウンロードして展開します
2. Chrome で `chrome://extensions` を開き、右上の **デベロッパーモード** をオンにします
3. **パッケージ化されていない拡張機能を読み込む** で `chrome-extensions/persona-mode/extension` を選びます

動作環境：Chrome 116 以降

## 使い方

1. 確認したいページを開き、ツールバーのアイコンでサイドパネルを開きます
2. **だれになって見る？** からペルソナを選ぶと、見え方が変わり、つまずきとひとりごとが出ます
3. つまずきの項目をクリックすると、ページの該当箇所へ移動します（言葉の指摘は、ページ内の該当語を強調）。見出しをクリックすると、該当箇所すべてに枠を表示します
4. **結果をコピー** で、ひとりごとと指摘をまとめたテキストを Slack などに貼れます
5. **解除** か、サイドパネルを閉じると、見え方・ズームが元に戻ります

### ヒント

- 「片手・急ぎ」は、スマホの画面幅で見ると正確です（デベロッパーツールのデバイスモードで、iPhone などを選んでから使ってください）
- 「低速回線」の実際の遅さは、デベロッパーツールの「ネットワーク」で通信速度を「低速 4G」などに制限して確認できます。この拡張機能は、ページの重さから表示時間の目安を計算します
- Chrome内蔵AI（Gemini Nano）が使える環境では、「実況してもらう」でAIがひとりごとを作ります（端末内で処理され、外部には送られません）。初回は設定欄のボタンからモデルの準備が必要です

## 注意

- 見え方の再現は目安です。実際の見え方には個人差があります
- 色の差（コントラスト比）は背景色から計算します。背景画像の上の文字は正しく計算できません
- ページの重さは、ブラウザが測れるファイルだけを数えます（外部サーバーのファイルはサイズがわからない場合があります）
