# フィードバック翻訳機（Chrome拡張機能）

「もっとパッと目立つ感じに」「なんか読みにくい」といった**曖昧な要望を、具体的な修正内容に変換**するツールです。
ページ上の要素を選ぶと、その要素の**実際のCSSの値**（文字サイズ・太さ・色・余白など）を読み取り、要望に合わせた修正案を数値で出します。

- 修正案はその場で**ページに当ててプレビュー**できます（打ち合わせ中にクライアントへ見せられます）
- **開発者向けの修正依頼**（変更前後の表・CSS）と、**クライアント向けの説明文**を書き分けます
- 要素のスクリーンショットを撮り、**GitHub Issue の作成画面**を本文入りで開きます
- 逆向きに、エンジニアの説明を**やさしい言葉に言い換える**こともできます

修正案はルールで作るため、AIがなくても動きます。Chrome内蔵AI（Gemini Nano）が使える環境では、文面の言い換えにAIを使えます（端末内で処理され、外部には送られません）。

## インストール

1. このリポジトリを GitHub の「Code → Download ZIP」でダウンロードして展開します
2. Chrome で `chrome://extensions` を開き、右上の **デベロッパーモード** をオンにします
3. **パッケージ化されていない拡張機能を読み込む** で `chrome-extensions/feedback-translator/extension` を選びます

動作環境：Chrome 116 以降

## 使い方

1. 確認したいページを開き、ツールバーのアイコンでサイドパネルを開きます
2. **ページ上で要素を選ぶ** → 指摘された箇所をクリック（`↑` `↓` キーで選択範囲を親・子の要素に広げたり狭めたりできます）
3. 先方の要望を入力し（よくある要望はボタンで入力できます）、**修正案を作る**
4. 修正案のチェックを付け外しして、**ページでプレビュー** で確認します
5. **書き出し** で「開発者向け」「クライアント向け」を切り替えてコピー、または **GitHub Issueを作成**

### 読み取れる要望の例

| 要望の言葉 | 主な修正案 |
| --- | --- |
| 目立たせたい・パッと・地味・埋もれている | 文字を大きく・太く、色の差を大きく、ボタンの余白と影、周りの余白 |
| 主張が強い・うるさい・派手 | 太さを抑える、少し小さく、色の差を弱める（読みやすさの基準は維持）、影をなくす |
| 読みにくい・見づらい | 16px以上、行間1.8、文字間、コントラスト比、1行の長さ |
| 大きく・小さく・大きすぎる | 文字サイズ（ボタンは余白も）、画像やエリアは幅 |
| 窮屈・ゆとりがほしい／間延び・スカスカ | 内側・外側の余白、行間 |
| 高級感・上品・洗練 | 文字間を広げる、明朝体、細め、ボタンの角をシャープに |
| 親しみやすく・やわらかく | 角を丸く、丸ゴシック |
| 信頼感・きちんと | ゴシック体、角の丸みを抑える、見出しを太く |
| 押しやすく・ボタンっぽく | 高さ48px、余白、影、リンクに下線 |
| 古い感じ・垢抜けない | 角丸、影を薄く、文字の影をなくす、行間 |
| 太く／細く、濃く／淡く、行間・文字間を広げて／詰めて、中央に揃えて | それぞれの値 |

白い文字のボタンのように**文字色ではコントラストを上げられない場合**は、背景色を濃くする案を出します。

### 専門用語 → やさしく

「CLSを改善するため…」のような説明を、「表示中にレイアウトがずれる度合い（CLS）を…」のように置き換えます。最初に出てきた用語だけ（専門用語）を残し、2回目以降はやさしい言葉だけにします。

## 設定

- **GitHub リポジトリ**（`owner/repo`）：Issue の作成先。APIキーは不要で、作成画面を開くだけです。スクリーンショットはクリップボードにコピーされるので、本文に貼り付けてください
- **ラベル**、クライアント向け文面の **署名**
- **AI**：Chrome内蔵AIの状態。初回はモデルのダウンロードが必要で、設定画面のボタンを押したときだけダウンロードします

## 注意

- コントラスト比は背景色から計算します。背景画像の上の文字は正しく計算できません
- 修正案は「方向性のたたき台」です。最終的な値はデザイナーと相談してください
- プレビューはその場の見た目を変えるだけで、ページを再読み込みすると元に戻ります

## 開発者向け

```sh
node --test chrome-extensions/feedback-translator/test/unit.test.mjs   # 単体テスト
node chrome-extensions/feedback-translator/test/e2e.mjs                # Chromiumでの動作テスト
```

共通部品（`extension/shared/`）は `chrome-extensions/_shared/` が正本です。変更したら `node chrome-extensions/_shared/sync.mjs` を実行してください。
