# 参考サイト・コラージュ（Chrome拡張機能）

クライアントの「こんな感じで」を、**構成案のたたき台**にするツールです。
参考サイトで気になるセクションをクリックすると、中の **見出し・文章・画像・ボタン・入力欄の位置と大きさを読み取って、グレーのワイヤーフレームに変換** します。

- 「ファーストビュー」「料金・プラン」「よくある質問」などの **種類を自動で判定**（手で直せます）
- 複数のサイトから集めたセクションを **並べ替えて**、メモを付けて構成案に
- 全体を **ワイヤーフレーム画面** で確認（参考サイトのスクリーンショットと並べて表示）
- **SVG**（Figma にドラッグ＆ドロップで編集可能な図形として読み込めます）・**PNG**・**Markdown の構成案** で書き出し
- 案件ごとに **ボード** を分けて管理

## インストール

1. このリポジトリを GitHub の「Code → Download ZIP」でダウンロードして展開します
2. Chrome で `chrome://extensions` を開き、右上の **デベロッパーモード** をオンにします
3. **パッケージ化されていない拡張機能を読み込む** で `chrome-extensions/reference-collage/extension` を選びます

動作環境：Chrome 116 以降

## 使い方

1. 参考サイトを開き、ツールバーのアイコンでサイドパネルを開きます
2. **セクションを摘む** → 気になるセクションをクリック
   - カードの中などをクリックしても、セクション全体を選びます
   - `↑` `↓` キーで、選ぶ範囲を親・子の要素に広げたり狭めたりできます
3. 別の参考サイトでも同じように摘み、`↑` `↓` ボタンかドラッグ（`⋮⋮`）で順番を並べ替えます
4. 種類を直したり、「うちも実績の数字は3つ並べたい」などのメモを書いたりします
5. **ワイヤーフレームを開く** で全体を確認し、SVG / PNG / 構成案（Markdown）で書き出します

### ワイヤーの見方

| 形 | 元の要素 |
| --- | --- |
| 濃いグレーの帯 | 見出し（H1〜H6、または大きく太い文字） |
| 薄いグレーの線 | 文章（行数もおおよそ再現） |
| 角丸の枠 | ボタン |
| ×印の入った箱 | 画像・動画・地図（背景画像を含む） |
| 白い枠 | 入力欄 |
| 丸 | アイコン（48px以下の画像） |
| 薄い枠のカード | 繰り返し並んだカード（枠線・背景・影のあるもの） |

ワイヤーフレーム画面の「参考サイトの文言を表示」をオンにすると、見出しやボタンに元のサイトの文言を表示します（既定ではオフ）。

### 自動で判定する種類

ヘッダー / ファーストビュー / 特徴・サービス / 料金・プラン / よくある質問 / お問い合わせフォーム / お客様の声・事例 / お知らせ / 流れ・ステップ / 実績の数字 / 取引先・ロゴ / ギャラリー / CTA / フッター / コンテンツ

## 注意

- スクリーンショットは、セクションの上端から画面に収まる範囲を撮ります（縦に長いセクションは途中まで）
- 集めたデータはこのパソコンの Chrome の中（IndexedDB）に保存されます
- 参考サイトのデザインや文言には著作権があります。構成の参考にとどめ、そのまま使わないでください

## 開発者向け
