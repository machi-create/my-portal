# Tab Diet — タブ整理 & メモリ節約 Chrome拡張

管理シートやツールのタブを開きまくって Chrome が重くなる問題を、
**「よく使うページへの即アクセス」** と **「使っていないタブのメモリ解放」** の両面から軽くする拡張機能です。

Manifest V3 / 外部通信ゼロ / データはすべてブラウザ内に保存されます。

---

## インストール手順（開発者モード）

1. このフォルダ（`extension/tab-diet`）をPCの好きな場所に置く
2. Chrome のアドレスバーに `chrome://extensions` を入力して開く
3. 右上の **デベロッパーモード** をオンにする
4. **パッケージ化されていない拡張機能を読み込む** をクリック
5. `tab-diet` フォルダ（`manifest.json` が入っているフォルダ）を選択
6. ツールバーのアイコンをクリックするとサイドパネルが開きます
   - キーボードなら **Alt + Shift + T**
   - アイコンが隠れている場合はツールバーのパズルマークからピン留めしてください

> Chrome 114 以降が必要です（サイドパネル機能のため）。

---

## 4つの画面でできること

### 1. リンク — よく開くページに即アクセス

**ジャンルタブで分類できます。**初期は「管理シート」「業務ツール」「情報収集」「その他」の4つです。

| 操作 | やり方 |
| --- | --- |
| 絞り込み | ジャンルのタブをクリック（「すべて」で全ジャンルを横断表示） |
| ジャンルを追加 | タブ右端の **＋** |
| 名前変更・並べ替え・削除 | タブ右端の **⚙**（ジャンルの管理） |
| リンクのジャンル変更 | リンクをジャンルのタブへ**ドラッグ&ドロップ**、または ✎ から選択 |

- ジャンルは4つに固定ではなく、**いくつでも増減できます**（最低1つは残ります）
- ジャンルを削除しても、**中のリンクは先頭のジャンルへ移動する**ので消えません
- 各タブには登録件数が表示されます

登録と利用は次のとおりです。

- 表示中のページを **「＋ 今のページ」** でワンクリック登録（選択中のジャンルに入ります）
- **「タブから」** で開いているタブをまとめて登録（登録先のジャンルを選べます）
- 同じジャンル内はドラッグで並べ替え
- **クリックすると、すでに開いているタブがあればそのタブに切り替えます**
  → 同じシートを何枚も開いてメモリを食う、が起きなくなります
- 開いているリンクには緑の「開いています」バッジが付きます

### 2. タブ — いま開いているタブの整理

- 全ウィンドウのタブを一覧・検索（最後に見てからの経過時間つき）
- **重複を整理**: 同じページを開いているタブを検出し、1本だけ残して閉じる
- **放置をスリープ**: 設定時間より長く放置されたタブのメモリを解放
- チェックを付けて、まとめてスリープ / 退避 / 閉じる

### 3. 退避 — 「あとで見る」タブを保存して閉じる

- **このウィンドウを退避** / **表示中以外を退避**
- タブのURLだけ保存してタブは閉じるので、**メモリはすぐ解放されます**
- あとから1クリックで開き直せます（1本ずつ / まとめて）
- 退避には名前を付けられます（「月曜の請求まわり」など）

### 4. 設定

| 項目 | 内容 |
| --- | --- |
| 放置タブを自動スリープ | 一定時間さわっていないタブを自動でメモリ解放（既定: ON / 30分） |
| ピン留めタブを保護 | 常用タブはスリープさせない |
| 音が鳴っているタブを保護 | 音楽・Web会議を止めない |
| スリープさせないURL | 1行に1つ。URLの一部でOK（例: `docs.google.com`） |
| アイコンにタブ数を表示 | 開きすぎたら赤く警告 |
| #以降の違いを無視 | `#gid=…` 違いの同じシートを1つとして扱う |
| 閉じる前に確認 | まとめて閉じる操作の前に確認ダイアログを出す |

設定・ジャンル・リンク・退避データは JSON でエクスポート / インポートできます（PC間の引っ越し用）。
以前のバージョン（グループ名方式）のデータは、起動時に自動でジャンルへ変換されます。

## 「スリープ」とは？

Chrome の `tabs.discard` を使い、**タブは残したままメモリだけを解放する**機能です。

- タブのタイトルとURLはそのまま残ります
- クリックすると自動で読み込み直されます
- 1タブあたり数十〜数百MBの解放が見込めます（サイドパネルの「MB節約（目安）」は 1本=100MB として計算した概算値です）

**保護されるタブ**（スリープしません）
- 表示中のタブ / ピン留め（設定ON時） / 音が鳴っているタブ（設定ON時）
- `chrome://` などブラウザの内部ページ
- 除外リストに書いたURL

> 入力中のフォームがあるページは Chrome 側がスリープを拒否することがありますが、
> 確実に残したいページは除外リストに追加しておくのが安全です。

## メモリを減らすための使い方のコツ

1. **同じページを二度開かない** — 管理シートは全部「リンク」に登録して、そこから開く
2. **今日使わないタブは「退避」** — 閉じるのが怖いタブこそ退避すればメモリが空く
3. **自動スリープは30分から** — 慣れてきたら15分に縮める
4. **タブ数バッジを目安にする** — 25本を超えたら赤くなるので、整理のサイン
5. **Chrome標準のメモリセーバーと併用可** — `chrome://settings/performance` もONにしておくと効果的

## 権限について

| 権限 | 用途 |
| --- | --- |
| `tabs` | タブ一覧の表示、切り替え、スリープ、重複検出 |
| `storage` | 設定・リンク・退避データの保存（ローカルのみ） |
| `sidePanel` | サイドパネルの表示 |
| `alarms` | 1分ごとの放置タブチェック |
| `favicon` | 一覧にファビコンを表示（ブラウザのキャッシュを利用、追加の通信なし） |
| `system.memory` | PC全体のメモリ使用率の表示 |

ページの中身を読み取る権限（host_permissions / content script）は一切使っていません。
収集したデータを外部に送信することもありません。

## ファイル構成

```
tab-diet/
├── manifest.json        … 拡張の定義（Manifest V3）
├── common.js            … 設定・URL判定・スリープ判定など共通ロジック
├── background.js        … service worker（自動スリープ、バッジ更新）
├── sidepanel/
│   ├── sidepanel.html   … サイドパネルの画面
│   ├── sidepanel.css    … Machi Portal と同じトーンのダークUI
│   └── sidepanel.js     … 画面のロジック
└── icons/               … アイコン（16/32/48/128px）
```
